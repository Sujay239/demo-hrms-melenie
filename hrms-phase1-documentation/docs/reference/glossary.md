# Glossary

## Purpose
Keep terminology consistent.

- **Platform**: shared SaaS operator scope.
- **Tenant / Company**: isolated customer organization.
- **Tenant Context**: server-verified tenant scope.
- **New Hire**: pre-employment onboarding user; not Employee.
- **Document**: logical managed record with one or more immutable file versions.
- **Sensitive Document**: record requiring stricter permission/audit.
- **Common Holiday**: region/company-wide holiday.
- **Flexible Holiday**: eligible option an employee may select.
- **Audit Log**: append-oriented security/business event, distinct from operational log.
