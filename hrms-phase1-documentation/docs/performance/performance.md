# Performance Specification

## Purpose
Define end-to-end practices.

- Bounded list APIs.
- Indexed tenant filters/sorts.
- N+1 prevention.
- Efficient database aggregation.
- Concurrency for independent dashboard/aggregate work.
- Explicit partial failure rather than fake zeros.
- File streaming/controlled storage transfer.
- Route/lazy frontend loading.
- Tenant-aware cache keys/invalidation.
- Production performance targets must be measured/approved, not invented.
