# Future Roadmap

## Purpose
Record likely future directions without turning them into Phase 1 requirements.

## Future Phase: Configurable / drag-and-drop dashboard widgets
Possible future design: widget catalog, tenant/role defaults, per-user layout, responsive placement, keyboard-accessible reordering, layout persistence, versioned widget contracts and reset/default controls.

Phase 1 must not create widget-layout tables, customization endpoints or editor UI.

## Other future directions
- Advanced tenant colors/fonts/themes.
- Payroll and jurisdiction-specific calculations.
- Advanced reporting/analytical read models.
- SSO/SAML/OIDC/SCIM.
- Integrations/webhooks.
- Native e-signature.
- Consent, retention, subject access/export/deletion, data residency and legally verified GDPR/regional privacy controls.
