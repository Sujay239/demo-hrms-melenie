# New Hire Onboarding Portal Design

## Purpose
Specify the restricted Phase 1 New Hire experience.

## Shell
Simple tenant-branded shell with white logo area and onboarding-only navigation.

## Dashboard
Show:
- welcome/offer state;
- personal-details completion;
- fun fact completion;
- required-document checklist;
- acknowledgement status;
- signed-document status;
- overall verification/completion.

## My Details
Collect only fields authorized for pre-employment onboarding. Clearly distinguish required and optional fields. Preserve progress safely.

## Offer Letter
Actions:
1. Review
2. Download
3. Instruction to sign using a third-party application
4. Upload Signed Copy
5. View verification status

There is no “Sign here” native digital-signature control in Phase 1.

## Documents
Each requirement shows category, guidance, current upload/version, validation status, and replace/new-version action if allowed.

## Acknowledgement
Capture Name, Place, Date and confirmation. Support download of the acknowledgement artifact where generated by the business workflow. Signing remains external; signed artifact returns via secure upload.

## Completion
A New Hire cannot self-promote to Employee. HR verification and authorized conversion control that lifecycle transition.

## Error/Recovery
Expired access, rejected files, incomplete tasks, and verification rework have explicit next steps without opening unrelated tenant navigation.
