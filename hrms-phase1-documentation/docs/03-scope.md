# Phase 1 Scope

## Purpose
Prevent scope ambiguity and future-feature leakage.

## Included
Authentication, authorization/RBAC, tenancy, consultants, tenant lifecycle, employees, hierarchy, onboarding, offer letters, documents, regions, departments, designations, leave, holidays, attendance/overtime, fixed dashboards, knowledge base, announcements, tickets, buildings/rooms/reservations, audit, responsive UI, security, testing and DevOps foundations.

## Explicitly excluded
- Future only: Configurable / drag-and-drop dashboard widgets.
- Dashboard layout persistence/widget placement APIs.
- Custom tenant colors/fonts/CSS/theme builder.
- Payroll.
- Advanced reporting/BI.
- Native digital signature.
- Enterprise SSO.
- Advanced integration marketplace.
- Implemented/certified GDPR workflows, consent center or data residency enforcement.

## Future Phase
### Future Phase: Configurable / drag-and-drop dashboard widgets
May later add widget catalog, layout persistence, responsive placement, accessible keyboard reordering and customization permissions. None of those are Phase 1.

### EU/privacy
Future legal/policy-backed work may add consent, retention, export, deletion, residency and data-subject workflows.

## Scope rule
Extensibility is allowed. Speculative Phase 1 product behavior is not.
