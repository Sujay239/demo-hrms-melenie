# Development Phases

## Purpose
Give the implementation agent a dependency-aware execution order.

## Phase 0 Foundation
Project/tooling, error model, request IDs, DB/migrations, `/api/v1/`, logging, health checks.

## Phase 1A Identity and tenancy
Authentication, roles/permissions, trusted tenant context, consultant assignments, tenant lifecycle, negative isolation tests.

## Phase 1B Organization
Regions, departments, designations, employees, manager hierarchy, tenant shell/branding.

## Phase 1C Document platform
Private storage abstraction, metadata, categories, associations, versions, upload/download, sensitivity and audit.

## Phase 1D Onboarding
New Hire lifecycle, tasks/details, offer letters, acknowledgements, external-sign/upload and HR verification.

## Phase 1E Leave/holiday/attendance
Policy engine, balances/ledger, requests/approvals, regional holidays, clocking/corrections/overtime.

## Phase 1F Knowledge/service
Knowledge base, announcements, tickets/comments/attachments/activity.

## Phase 1G Facilities/dashboard
Buildings/floors/rooms, reservations, fixed role dashboards and concurrent independent metrics.

## Phase 1H Hardening
E2E/security, performance/index review, accessibility, monitoring, backup/recovery and consistency audit.

## Future
Future only: Configurable / drag-and-drop dashboard widgets, advanced themes, payroll, analytics, SSO, integrations and verified privacy/compliance implementation.
